# Wiki de Bloodborne

Bienvenido al proyecto **Wiki de Bloodborne**. Esta es una página web dedicada a proporcionar información detallada sobre el videojuego *Bloodborne*. El sitio está diseñado con HTML, CSS y JavaScript para ofrecer una experiencia de usuario interactiva. A continuación se detalla cómo instalar, configurar y utilizar el proyecto.

## Descripción

**Bloodborne** es un videojuego de rol y acción desarrollado por *From Software* y dirigido por *Hidetaka Miyazaki*. El juego sigue al protagonista, el Cazador, en su lucha a través de la ciudad de Yharnam, donde los habitantes se han visto afectados por una enfermedad de transmisión sanguínea. El objetivo del Cazador es buscar "sangre pálida" para finalizar la cacería, mientras enfrenta numerosos desafíos, enemigos y jefes.

El sitio web incluye información sobre el desarrollo, las críticas y una lista interactiva de tareas que los jugadores deben completar al comenzar su aventura.

## Características

- **Navegación Interactiva**: Incluye un menú de navegación con enlaces a varias secciones como *Armas*, *Jefes y Enemigos*, y *NPCs*.
- **Lista de Tareas**: Los jugadores pueden agregar tareas para prepararse para la caza en Yharnam y marcar las tareas completadas.
- **Sección de Críticas**: Revisión del videojuego por parte de importantes plataformas como *Game Informer*, *GameSpot*, y *GamesRadar*.
- **Diseño Responsivo**: El sitio es completamente funcional en dispositivos móviles y escritorios gracias a su diseño adaptativo.
- **Estilo Visual Atractivo**: El diseño visual sigue un tema gótico-victoriano que refleja la atmósfera de *Bloodborne*.

- `index.html`: El archivo HTML que contiene la estructura del sitio web.
- `styles.css`: El archivo CSS que da estilo y diseño a la página web.
- `scripts.js`: El archivo JavaScript que maneja la funcionalidad de la lista de tareas y la navegación del menú.

## Funcionalidad

### Menú de Navegación

El menú de navegación tiene enlaces a diferentes secciones que incluyen información sobre *Armas*, *Jefes y Enemigos*, *NPCs* y más. Se puede interactuar fácilmente con el menú incluso en dispositivos móviles gracias a un menú desplegable (hamburguesa).

### Lista de Tareas

Los jugadores pueden añadir tareas al comienzo del juego, como mejorar al personaje, elegir un arma y hablar con los NPCs. Las tareas se pueden marcar como completadas con un simple clic.

### Sección de Críticas

El sitio muestra críticas de diferentes plataformas de videojuegos que elogian la atmósfera, jugabilidad y los aspectos visuales de *Bloodborne*. Cada crítica incluye una puntuación y una breve descripción de los puntos destacados.

## Tecnologías Utilizadas

- **HTML5**: Para la estructura de la página.
- **CSS3**: Para el diseño y estilo de la página web.
- **JavaScript**: Para la interacción dinámica de la lista de tareas.
- **SVG**: Para los íconos del menú y botones.
